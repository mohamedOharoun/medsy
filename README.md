# Medsy (2026)

Medsy is a mobile application designed to simplify medication management, track treatment adherence, and support caregivers. This app empowers users to take control of their health routines, offering reminders, inventory tracking, and seamless family profile management.

## Features
### Medication Management & Adherence

|Field|Description|
|:---:|---|
|Treatment Tracking|CRUD of own current medications, including dosages and frequencies|
| Intake History | View of the complete intake history to monitor treatment adherence |
| Inventory & Refills | Track the amount of medication left in order to see it will be necessary to refill |
| Smart Search | Filter medications by active substance, commercial name, or administration method |
| Medication Insights | Read official medication leaflets and explore alternative medications |
| Allergy & Interaction Warnings | Warnings about potential drug interactions and allergic substances |


### Caregiver & Family Support

|Field|Description|
|:---:|---|
|Family Management|CRUD of family members under a single account|
| Remote Tracking | Easy medication treatments management and monitor  for care recipients directly from their own devices |
| Role-Based Access | Navigation between the personal data and the assigned family members' data |


### Smart Notifications

|Field|Description|
|:---:|---|
| Reliable Reminders | Offline-capable, scheduled notifications |
| Interactive Alerts | Confirm dose directly from the notification |
| Customizable Alerts | Tailor notifications to receive only the reminders needed |


### Accessibility & Personalization
|Field|Description|
|:---:|---|
| Elderly-Friendly UI | Intuitive and simple interface |
| Visual Customization | Adjust text presentation and formatting |


### Others

|Field|Description|
|:---:|---|
| Account Management | Secure account creation, login, updates, and deletion across devices |
| Data Protection | End-to-end encryption for user profiles and medication-tracking data |
| Reliable Database | Periodic synchronization with the national medication repository |
